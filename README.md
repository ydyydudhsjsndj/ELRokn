# ELRokn — Damascene Corner Menu

A responsive, bilingual Arabic/English restaurant menu built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your `ELRokn` repository.
2. Commit the files to the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`.
4. Visit `https://ydyydudhsjsndj.github.io/ELRokn/`.

## Notes
- Menu items and prices are demo data. Edit the `items` arrays in `script.js`.
- The approved palette is `#12110F`, `#EAB51D`, `#F7F0E3`, `#762D24`.
- Food photography and web fonts use external providers, so they require an internet connection. The page itself has no backend.
- This is a static menu only; it does not accept or send orders.
